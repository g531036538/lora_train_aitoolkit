逐张校对

问题只按 severity 上色（error 红 / warn 黄 / info 正常），不存在「某几种 code 才标红」的白名单；原因直接显示 check_captions() 给的 message 原文。改完点「保存这张」立即写回同名 .txt。

训练参数与导出

参数默认值全部来自 default_plan() / VRAM_TIERS（留空即用库的默认），校验走 validate_config_detailed：只有存在 severity=error 的项才禁止导出，warn 会照常显示但仍可导出。
